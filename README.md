# MN Pet

MarginNote 独立桌宠插件，当前正式版本为 1.0.3，作者乔木Joe。要求 MarginNote 4.5.0 或更高版本，正式安装包为 `MN Pet-v1.0.3.mnaddon`。

保留哦鲸鲸、图片与 `.mnpet` 动作包的显示和切换、导入、图片裁剪与编辑、删除、拖动、点击反馈及自定义事件倒计时。桌宠动作随状态自动切换：待机播放 `idle`，专注中播放 `focus`，休息中播放 `rest`，拖动时播放 `drag`，包里缺少对应动作时回落到 `idle`；点击时从 `happy/wave/shy/bow/sleep/step` 中随机播放一个，六个都没有则改为挤压回弹。点击桌宠展开时间气泡：上方同排显示事件和天数，中间大字显示当前计时，下方显示计时状态；点击桌宠右上角三横线展开基础计时面板。

右上角使用宽约 296、高度随实际内容收紧的基础计时器，顶部依次为倒计时、番茄钟、正计时，保留科目、时间、进度及基本操作。倒计时可在设置中指定 1–720 分钟，结束自动记入一次专注，不自动循环；正计时点击“记录”只保存新增部分，连续记录不会重复累计，重置清空未记录时间。开始计时后锁定科目，暂停时也不能更换、添加或删除，完成或重置后解锁；多个窗口执行同一规则。面板不显示关闭按钮，点击面板外或再次点击三横线可收起，计时继续。外部点击区域随当前窗口布局，收起、后台与销毁时移除。底栏“设置与统计”直接打开主面板“计时”页。小面板固定缩放比例，禁用滚动、回弹和捏合缩放，较小窗口会收紧布局。科目在面板内翻页选择；提示变化时主动更新面板高度，并预留底部间距，确保保存结果完整显示。面板高度与内容不一致时会重新对账收紧，不会停在多余空白上。

在 MN 插件工具栏点击 MN Pet 图标打开设置，采用参考 Daguanyuan Bridge 的独立悬浮胶囊导航，周围透明、滚动时保持可见，分为“桌宠”“计时”“统计”“关于插件”四页。桌宠页集中管理展示、切换、导入与外观；计时页的倒计时与番茄钟分别使用独立卡片和保存按钮，保存时保留另一部分的未保存草稿，下面管理科目、科目预设与通用提醒，事件倒计时保留在最下方。专注统计独立为第三页，可查看今天、近 7 天、近 30 天；每个科目一根柱子比较时长，也可切换为扇形图查看占比，图表和科目列表使用同一配色，时间分布另行保留。连续专注卡片显示当前连击与历史最长天数，下方用按周对齐的方格热力图展示每日专注量，面板够宽时一眼看全 53 周，变窄则从最早一侧裁掉整周、始终保留最近的日期且不需要横向滚动，行列分别标注月份与星期，颜色分四档加深，今天之后的格子留空；当天尚未开始不计作中断。关于页显示插件名称、版本及作者乔木Joe。番茄钟默认 25/5/15 分钟，每完成 4 个专注进入长休息。主面板和小计时器共用计时状态，统计范围独立。两个面板都保持 1 倍比例，双指捏合和双击不会放大页面；主面板仍可正常上下滚动，输入框字号统一为 16px 以避免 iOS 聚焦时自动放大。外观、菜单显示模式、结束提醒与事件倒计时即时保存，倒计时和番茄钟时长分别点击保存后生效。桌宠文件保存在 MN 文档目录中的 `MN-Pet` 文件夹，使用独立的设置命名空间，不读写 Ai Bridge 数据。

主设置面板的四个页面使用统一内容宽度，主要卡片上下排列，宽屏仅在卡片内部并排展示字段及图表明细，小窗口自动换行；科目管理和预设默认折叠，事件倒计时仍在最下方。统计顶部在一张概览卡片中展示今天、所选范围和累计时长，输入框、按钮与说明文字统一尺寸和间距。两种计时设置分别显示未保存状态，保存结果显示在各自卡片中。

主设置和计时面板均在后台校验页面是否完成初始化；空页、脚本不响应或加载超时会触发一次自动重建，仍未恢复时显示重试按钮，不显示遮挡内容的加载横条。健康页面关闭再打开时保留输入草稿。

番茄钟设置、状态和统计一起原子保存到 `MN-Pet/pomodoro.json`。收起气泡、隐藏桌宠或关闭设置后继续按实际时间计时。应用在后台时不保证提醒即时出现，回到前台后校正并处理到期阶段；超时超过 10 分钟时不自动启动下一阶段。专注在其结束时归档，正计时在点击记录时归档。计时存档经 UTF-8 JSON 文本原子读写，隔离统计与科目预设；遇到预设中混入同一份完整日统计的历史存档，会先在 `MN-Pet` 目录保存 `pomodoro-backup-*.json` 原始备份，再移除错位副本，保留统计及计时状态。无法确认的损坏仍保留原文件。

开发时运行 `npm ci` 安装依赖，`npm run check` 检查语法和运行环境，`npm test` 验证功能，`npm run build` 生成固定测试包 `MN Pet Test.mnaddon`。正式构建使用 `npm run build:release`，版本由用户确认后指定，同名正式包禁止覆盖。

本地测试和浏览器预览用于验证逻辑与界面，MN 的真实触控、文件选择和窗口行为需要安装测试包后确认。

气泡 SVG 与动画样式来自 DeepSeek Balance Whale Widget，保留 MeteorNOX 的 MIT 许可与来源记录。角色资源出处与处理记录见 `assets/pet`。这些说明适用于相应复用资源，不代表其余项目代码整体采用 MIT。

计时功能参考用户提供的 EZ_time 1.3.2 的交互行为，采用本项目独立实现，不导入或修改其存档。插件图标使用用户提供的图片。
